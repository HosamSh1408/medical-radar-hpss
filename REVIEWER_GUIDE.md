# Examiner & Supervisor Code Review Guide

This guide helps thesis examiners navigate, inspect, and independently verify the repository in **10–15 minutes** without wading through `19,300+` lines of orchestration, plotting, and clean-room audit boilerplate.

---

## 1. Why the Experimental Code Is Kept Bit-for-Bit Unmodified

All empirical numbers, tables, statistical tests, and vector figures in the thesis monograph are cryptographically bound to sealed branch **`thesis/main`** (commit `5e458c1`) via **[`audit/thesis_freeze_manifest.sha256`](audit/thesis_freeze_manifest.sha256)** (`113/113` SHA-256 hashes) and frozen Stage 4 model archive **[`thesis/outputs/stage3_uncertainty/frozen_stage4_models.npz`](thesis/outputs/stage3_uncertainty/frozen_stage4_models.npz)** (SHA-256 `af33a83e157f7d2efb0f47e50c9544ee19bacb7da88ab0e0235ccead029cbcc4`).

Refactoring `thesis/*.py` or `paper_workspace/src/*.py` in place would break those cryptographic locks cited in the Declaration of Authorship and Appendix C. Instead, this submission branch (`thesis/manuscript`) adds a clean **Supervisor Review Layer** (`README.md`, this guide, `verify_submission.py`, `examples/filtersafe_tour.py`, and `notebooks/supervisor_code_tour.ipynb`) on top of the untouched, SHA-256-locked core.

## 3. Recommended 10-Minute Inspection Protocol

1. **Verify cryptographic integrity & run all automated tests (`~45 s`):**
   ```bash
   python3 verify_submission.py
   ```
   Confirms `113/113` SHA-256 freeze-manifest hashes, frozen archive `af33a83e...`, `31/31` portable pytest checks out-of-the-box on a fresh clone (causality, $O(2)\times\mathbb{R}_{>0}$ invariance, finite-difference BPTT gradients, HQI/conformal bounds, Stage 0–4 contracts; plus `4` full-corpus raw-data provenance checks that run automatically when the unbundled Zenodo/Figshare datasets are present for `35/35`), and prints live headline tables from `paper_orchestra_bundle/raw_materials/metrics_stage*.json`.
2. **Inspect the interactive browser demo & walkthrough (`0` setup / `~5 s` execution):**
   - Double-click **[`examples/session_7_3_live_demo.html`](examples/session_7_3_live_demo.html)** offline in any browser for live NICU Anchor Session `7.3` causal replay (`FilterSafe-8` vs. `R0`/`R3a`/`R3b`/`R3c`, `U2`/`U6b` abstention slider, and `20 bpm` bradypnea + WGN dropout stress views; rebuildable via `python3 examples/build_interactive_demo.py`).
   - View [`notebooks/supervisor_code_tour.ipynb`](notebooks/supervisor_code_tour.ipynb) directly on GitHub, **or** execute [`examples/filtersafe_tour.py`](examples/filtersafe_tour.py):
     ```bash
     python3 examples/filtersafe_tour.py
     ```
3. **Spot-check the two key algorithmic modules (~`200–300` lines each):**
   - `DifferentiableSymmetricHMM`, `bptt_hmm_adjoint`, and `CausalDilatedTCN` in [`thesis/diff_hmm_and_foils.py`](thesis/diff_hmm_and_foils.py).
   - `extract_zero_tuned_proxies_session` and `evaluate_finite_k_conformal_suite` in [`thesis/wp3_wp4_uncertainty_conformal.py`](thesis/wp3_wp4_uncertainty_conformal.py).
4. **(Optional) Verify the legacy `v1` baseline (`Python 3.9.6`):**
   ```bash
   python3 verify_submission.py --run-v1-baseline
   ```
   Full `19/19` legacy baseline checks require the full 33-session `beltrao_data/` corpus; on a fresh clone with tracked fixtures alone, the first 12 checks run on Anchor Session `7.3`.

## 4. Dual-Interpreter & Dataset Notes

- **Dual-Interpreter Provenance Lock:** Legacy `v1` baseline caches (`paper_workspace/outputs/cache/*.npz`, `33/33`) were generated and verified under `Python 3.9.6` (`paper_workspace/src/requirements-lock.txt`); Stages 0–4 (`thesis/`, `tests/`) execute under `Python 3.10+` (`requirements-thesis.txt`) reading those caches read-only.
- **Fresh-Clone Bundle Strategy:** Full raw clinical recordings (`beltrao_data/`, 33 sessions) and the 24.2 GHz phantom benchmark (`external_data/gleichauf2024/`, `3.58 GiB`) exceed GitHub blob limits and are excluded from Git via `.gitignore` (full SHA-256 manifests and Figshare/paper DOIs are tracked instead). Two small fixtures—[`frozen_stage4_models.npz`](thesis/outputs/stage3_uncertainty/frozen_stage4_models.npz) (`259 KB`) and Session `2.3` radar (`6.02 MB`, paired with Anchor Session `7.3`)—are tracked directly so all `31/31` portable unit/contract tests (`35/35` with full raw corpora), `113/113` freeze-manifest checks, and `examples/filtersafe_tour.py` run cleanly out-of-the-box after `git clone`.
